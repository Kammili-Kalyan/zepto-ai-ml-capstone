# Zepto AI/ML Capstone Project

## Project Overview

This repository contains my end-to-end Artificial Intelligence and Machine Learning capstone project.

The project contains three connected modules:

1. Data Pipeline
2. Analytics and Machine Learning
3. GenAI Support Assistant


## Modules

### 1. Data Pipeline

The data pipeline scrapes book data, cleans the data, converts prices from GBP to INR, stores the data in SQLite, and performs SQL and pandas analysis.

### 2. Analytics

The analytics module profiles and cleans the Titanic dataset, performs exploratory data analysis, builds classification models, performs model evaluation and tuning, and builds a regression model.

### 3. Support Assistant

The support assistant uses Zepto policy documents, embeddings, ChromaDB, LangGraph, and FastAPI to create a grounded policy-question answering service.
